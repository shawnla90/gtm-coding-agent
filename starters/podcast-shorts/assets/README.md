# assets

- `fonts/` — Inter 400/700 (latin subset), vendored under the SIL Open Font
  License 1.1 (see `fonts/OFL.txt`).
- `vendor/` — intentionally empty in the repo. `compose_overlay.py` fetches a
  pinned `gsap.min.js` (3.15.0) from jsdelivr on first run; GSAP ships under the
  GreenSock "no charge" license, which permits use but not redistribution here.
